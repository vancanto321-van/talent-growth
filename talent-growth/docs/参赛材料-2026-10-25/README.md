## 体验路径

打开线上地址，选择“进入全年龄探索”，浏览一项任务的材料与步骤，使用虚构信息保存记录，再到“星球”查看探索周报或作品与变化。首页“儿童档案”提供另一条家庭入口。

建议使用浏览器隐私窗口，结束后关闭窗口；或者在浏览器站点设置清除数据。不要输入真实儿童姓名、生日、照片或医疗资料。
