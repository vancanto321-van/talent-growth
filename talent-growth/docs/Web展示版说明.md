# Web 展示版与本地数据说明

## 适合怎样展示

本项目当前提供一个本地优先的 Web 展示版：不需要安装数据库或配置第三方 API 密钥，适合评审、课堂演示和个人试用。基础活动和记录功能不依赖互联网。

## 一键启动

在仓库根目录（包含根目录 `package.json` 的目录）运行：

```bash
npm start
```

然后打开：<http://127.0.0.1:4184/growth/>

要求 Node.js 22 或更高版本。Windows、macOS、Linux 均可。停止时在终端按 `Ctrl+C`。完整说明见根目录 [README](../../README.md)。

## 浏览器安装与离线使用

网页包含 PWA 应用清单和 Service Worker。首次使用时：

1. 通过 `npm start` 打开页面，不要直接双击 HTML 文件。
2. 等页面加载完成；浏览器可能在地址栏或菜单中显示“安装应用”。
3. 安装后可以从桌面或应用列表打开。
4. 首次在线打开并缓存完成后，基础页面可以离线打开。

离线限制：外部资料链接、作品链接和需要本机备份服务的账号操作仍需要相应服务；首次缓存需要网络或至少需要先在线加载一次。

## 数据保存与备份

| 数据 | 默认位置 | 需要注意 |
| --- | --- | --- |
| 方向档案、尝试、周报和作品文字 | 当前浏览器的 Local Storage | 同一浏览器、同一地址；清理站点数据或无痕模式可能造成不可恢复的丢失 |
| 孩子成长档案和照片 | 当前浏览器的 IndexedDB | 文本备份不包含照片文件，照片请另行保存 |
| 手动本机账号备份 | 仓库根目录 `.local-data/growth-sync/` | 仅本机服务使用，保留最近五个版本，不自动上传公网 |

换电脑或升级项目文件前：

1. 在「家人」中导出方向 JSON 备份。
2. 在孩子成长档案的备份入口导出对应备份。
3. 单独复制重要照片。
4. 保留 `.local-data/`，不要把个人备份上传 GitHub。
5. 在新环境恢复前先确认档案内容和隐私边界。

## 隐私边界

- 下载源码或打开本地 Web 版不会获得其他用户的记录。
- 默认数据留在当前浏览器和当前电脑。
- 云端或本机账号备份只有在用户主动操作时才发生。
- 文本备份不携带照片文件。
- 演示和参赛时只使用虚构数据，不使用真实儿童姓名、生日、照片或医疗信息。
- 本地 Web 版不是公网服务，不应直接暴露给互联网访问。

## 发布前检查

```bash
npm test --prefix talent-growth/app
npm run build:web
```

`build:web` 会在打包前强制运行完整测试；测试失败时不会生成新的发布包。当前阶段不包含 DMG 或 Windows 安装包。
