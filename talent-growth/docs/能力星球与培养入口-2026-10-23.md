## 14 个领域如何开始

| 领域 | 培养入口的核心动作 |
| --- | --- |
| 文学语言 | 同一件小事讲给不同听众，观察哪里需要换讲法 |
| 哲学 | 从公平问题提出理由，再找例子和反例 |
| 历史文明 | 从一件旧物或照片追问来源，交叉核对 |
| 美术设计 | 把看到的细节与自己的解释分开 |
| 音乐表演 | 听出并标记节奏，改变一个片段 |
| 数学逻辑 | 尝试不同解法，改变一个约束再看 |
| 自然科学 | 区分观察与解释，一次只改一个条件 |
| 数字计算 | 从想做的作品开始，调试并解释修改 |
| 手工工程 | 做材料与结构原型，比较后迭代 |
| 农业生态 | 观察照护对象，记录本地条件与变化 |
| 生活技能 | 规划一餐或共享任务，也允许先纸上模拟 |
| 关系表达 | 倾听、复述，再请对方核对 |
| 社会经济 | 从真实公共问题出发，说明约束与来源 |
| 身体运动 | 自选舒适的短活动，观察感受，不适时停止 |

同一个主题的差异不只是改标题：低龄侧重陪伴、感官和口述；学龄侧重选择、记录和比较；青少年增加证据、独立判断与合作；成人和长者结合生活、工作及再学习处境。已有基础决定提示多少，年龄不直接等于能力。

## 星球展示规则

1. 无直接记录：未探索。
2. 有合法日期、非空笔记或结果的直接记录：已遇见。
3. 至少两次，跨两个日期，且至少两条记录留下变化或反馈：正在回访。
4. 至少两次，跨两个日期，且有「用过有帮助」及具体结果说明：已有应用。

记录按 ID 去重，排除未来日期，按当前档案和活动年龄筛选。旧方向活动只显示为相关经历，不自动换算成学科经历。暂停不会自动变暗。阈值是产品展示规则，不是经研究验证的能力阶段、测验分数或百分位。

亮度反映记录积累；暗不表示缺陷。机会写成可尝试的作品、生活或工作场景；提醒指向缺失的反馈、未验证的用途或不合适的条件，不做职业、收入和未来成就预测。
