# 本机预览

新下载的仓库推荐使用[根目录快速开始](../../README.md)：在仓库根目录执行 `npm start`。该方式适用于 Windows、macOS 与 Linux，账号备份保存在仓库根目录 `.local-data/growth-sync/`，按 Ctrl+C 同时停止两个服务。下文是旧开发环境的 macOS launchd 托管说明；不要与新启动入口同时运行。

地址：<http://127.0.0.1:4184/growth/>，只能在运行服务的这台电脑上访问。

2026-10-22 修复：原终端预览进程已退出，4184 无监听进程。网页与备份开发服务现交由 macOS 当前登录会话的 launchd 托管，不依赖聊天终端的存活，进程退出后可自动重启。

在项目目录运行：

```sh
bash scripts/local-preview.sh start
bash scripts/local-preview.sh status
bash scripts/local-preview.sh stop
```

此配置没有安装到登录启动目录。电脑重启或退出登录后，需要重新运行 `start`。输出与配置位于 `outputs/local-preview/`；备份开发数据仍沿用 `/tmp/growth-journey-preview`，不作为正式云端备份使用。

本机预览监听 `127.0.0.1:4184`，备份开发服务监听 `127.0.0.1:18139`，没有向局域网开放。这次修复没有上传或修改腾讯云。
