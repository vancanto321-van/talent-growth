## 四、待处理（已知风险）

1. **HTTPS 证书为 IP 证书，有效期到 2026-10-29 04:42**。Let's Encrypt 的 IP 证书只有数天寿命，依赖 Caddy 自动续期；续期失败会导致整站 HTTPS 报错。
2. **80 端口不跳转 HTTPS**：`http://<服务器地址>/growth/` 直接返回 200。
3. **只有 IP、没有域名**：链接不便于分发，部分浏览器对 IP 证书会额外提示。

处理建议见 [域名与 HTTPS 配置](域名与HTTPS配置.md)。

## 五、复现步骤

```bash
# 1. 打包（会先跑 19 项测试）
cd talent-growth && node scripts/package-web.mjs

# 2. 上传
scp outputs/tencent-cloud/talent-growth-<releaseId>.tar.gz root@<服务器地址>:/tmp/
scp scripts/deploy-tencent.sh root@<服务器地址>:/tmp/

# 3. 部署（脚本自带 SHA 校验、Caddy 备份、失败自动回滚、逐文件比对）
ssh root@<服务器地址> "SITE_ORIGIN=https://<服务器地址> bash /tmp/deploy-tencent.sh \
  /tmp/talent-growth-<releaseId>.tar.gz <sha256> <releaseId>"
```

成功会输出 `DEPLOY_OK release=<releaseId> backup=<备份目录>`。
失败会自动回滚并输出 `DEPLOY_FAILED_ROLLED_BACK`，备份目录在 `/opt/child-growth/backups/`。
