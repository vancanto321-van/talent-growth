整理日期：2026-10-24，Asia/Shanghai。

## 1. 当前产品与状态

用户希望做一个自己和孩子都能使用的全年龄探索产品：从轻松的「三件小事」开始，发现兴趣，持续练习，留下作品、变化和反馈，逐步把能力用于生活和工作。允许随意开始、逐渐深入，不要求先定方向或全面打卡。

正式站点：<https://43.159.60.166/growth/>。

2026-10-23 已发布 v2.3.0，发布 ID `4c4aea843ff5b843`。这是最近一次发布时确认的状态，接手后如需判断实时线上情况，应重新读取 `/growth/release.json`。

- 624 个活动：原九能力方向 540 项，加十四学习领域的 84 个活动。
- 六个档案年龄组：0–2、3–6、7–12、13–17、18–59、60+。
- 十三个较细支持视角，包含成人不同处境；年龄不是能力等级，已有基础单独选择。
- 十四领域：文学语言、哲学、历史文明、美术设计、音乐表演、数学逻辑、自然科学、数字计算、手工工程、农业生态、生活技能、关系表达、社会经济、身体运动。
- 三十项学习资源，九项一般研究依据，十项领域来源。
- 底部导航为发现、培养、星球、家人。星球页内还有探索周报、作品与变化。
- 可选账号备份服务已经正式启动，支持手动上传、恢复最近五版；无自动合并、密码找回、家人邀请或照片文件同步。

## 2. 用户偏好和重要边界

- 年龄和能力用横向滑动选择条，尽量把视觉空间留给探索卡片。
- 项目详情有多个完成方向，五档电量由用户按标准填写。保存文字不自动充电。
- 保留轻量发现入口；研究依据、更多做法和资料按需展开，避免一开始堆满课程。
- 同主题需要按年龄、基础、生活处境改变材料、参与方式和产出，不能只换标题。
- 能力星球的亮度表示直接探索记录，暗淡不等于弱项，亮也不等于先天天赋。没有总分、排名、职业或收入预测。
- 可以给出机会与提醒，但应落实为可试的场景、需要补充的反馈或尚未验证的条件。
- 论文、机构框架、实践指南分别标明来源与适用边界；名校名称不表示其验证或推荐本产品。
- 用户曾要求暂不发布，之后已明确要求上传，并已完成上述发布。本次请求仅为打包交接，不表示授权新的线上改动。
- 不新增或运行测试，除非用户提出测试或验证需求。已有测试源码包含在包里；最近这轮使用语法检查、构建校验及手动页面查看，未运行自动化测试套件。

## 4. 运行和构建

建议 Node.js 22；线上发布时为 22.23.1。后端要求 Node 18+，但本机预览脚本使用 `import.meta.dirname`，因此整体接手建议直接用 Node 22。Python 3 用于辅助脚本；后端运行无需 Python。

在解压后的项目根目录：

```sh
cd app
npm ci
cd ..
node app/scripts/sync-data.mjs
node scripts/preview-journey.mjs
```

浏览器打开 <http://127.0.0.1:4184/growth/>。只启动网页时，账号备份不可用，但本地探索功能可用。

另开终端，从项目根目录启动本地备份开发服务：

```sh
GROWTH_SYNC_DEV=1 COOKIE_SECURE=0 GROWTH_SYNC_HOST=127.0.0.1 GROWTH_SYNC_PORT=18139 GROWTH_SYNC_DIR="$PWD/.local-data/growth-sync" GROWTH_SYNC_ORIGIN=http://127.0.0.1:4184 GROWTH_SYNC_ALLOWED_ORIGIN=http://127.0.0.1:4184 node server/growth-sync.mjs
```

`.local-data` 是接手后创建的私有运行数据，不要放进后续源码交接包或静态发布包。本次包内没有该目录。

macOS 还可用 `bash scripts/local-preview.sh start`，详见 `docs/本机预览.md`。此方式使用当前登录会话的 launchd；同机已有旧项目预览时，应先确认并停止旧服务再启动新目录，避免端口和固定 label 冲突。其他系统使用上面的两个终端方式。

构建静态发布包：

```sh
node scripts/package-web.mjs
```

输出到 `outputs/tencent-cloud/`。构建会同步数据并检查覆盖、字段、重复 ID、研究来源等，不会自动发布。

## 6. 数据与星球规则

方向数据主要使用浏览器 `localStorage` 的 `talent-growth-v1` 和 `talent-growth-previous-v1`；原成长记录与照片还有独立存储逻辑。保留旧 version 1 数据兼容、档案隔离、跨年龄保存限制、账号与 revision 双重校验，不用初始化覆盖读取失败的原始数据。

星球只把明确 `learningDomainId` 的活动计为学科直接记录，旧九方向任务仅列相关经历，不自动点亮学科。记录需有有效非未来日期及非空笔记或作品说明，按 ID 去重、按档案和年龄筛选。

- 无直接记录：未探索。
- 已有直接记录：已遇见。
- 至少两次、两个日期，且至少两条有变化或反馈：正在回访。
- 至少两次、两个日期，且有用过有帮助及具体结果自述：已有应用。

这些只是展示阈值，没有测量效度，不是标准化学习阶段。暂停不自动扣光。婴幼儿采用照护者的陪伴观察，不要求儿童达标或反复表现。

## 8. 优先继续完善的事

1. **内容深度**：原九方向满足每年龄每方向十项；新十四领域目前各只有一个主题项目的六年龄入口。两者覆盖口径不同，不能宣称十四领域各年龄也已十项目。扩充真实主题、材料、基础与应用场景，避免换词凑数。
2. **课程与资源衔接**：仍不是完整哲学、历史、文学艺术、农业或生活技能课程。资源目录不等于已经做完教材讲解与学习路径。
3. **更细支持**：档案仍是六组，十三支持视角已有，但不是连续年龄模型。成人与长者应结合已有基础、时间、处境，不以年龄推断能力。
4. **研究到活动**：本轮新增入口落实于 84 个领域活动，尚未把原 540 项逐项做研究审查。继续逐项目追溯，说明证据强弱，不承诺“最有效”或已经科学识别天赋。
5. **产品效果**：可以继续打磨体验与观察设计，但当前没有本产品的效果验证、标准化天赋测量或职业预测能力。
6. **账号恢复体验**：服务已上线，最近发布检查了健康接口和匿名状态；未创建真实线上账号进行备份恢复演练。
