## 一、可试用版本与完整体验步骤

1. 启动后端：`cd backend && uv run uvicorn app.main:app --port 8000`（默认 mock AI + 模拟登录/支付）
2. 启动前端：`cd frontend && npm run dev:h5` → http://localhost:5173（或微信开发者工具导入 `frontend/dist/dev/mp-weixin`）
3. 体验路径：首次进入 4 页引导 → 今日页三入口任选 → AI 访谈（6 题，可展开"为什么这么问"）→ 候选线索选 3 个开周期 → 今日任务（做任务→提交→AI 初评→自评→录入读者反馈）→ 画像（五维+培养路径+组合）→ 计划打卡 → 计划页"生成 4 周结业报告" → ¥9.9 解锁 → 开新一轮
4. 儿童版 / 行业测评从探测页进入；48 题测评后有行业排行与短板提升建议

## 二、测试证据

- 全量测试：**59 passed + 2 xfailed**（含本次新增：认证会话生命周期、审计修复回归、四周周期 E2E、AI 质量 26 用例）
- 认证：签名会话（HMAC-SHA256）签发→可用；篡改 uid/伪造签名→401；登出撤销→401；`ALLOW_MOCK_AUTH=false` 时明文令牌与 mock-login 关闭，而签名会话（正式微信用户）不受影响——**历史 bug「关模拟登录连带拒绝真实微信登录」已修复**
- 隔离：用户 B 访问用户 A 的任务/评估/计划/报告，全部 404（test_cross_user_isolation）
- 口径：同一模板重复提交只计 1 个证据；全 AI 辅助 → 当前表现为"待验证"；进步只按同阶段独立完成配对；较充分证据列出仍未验证事项
- 权益：child_assessment / cycle_report 按 scope_id 解锁——买 A 周期报告，B 周期仍锁定；月订阅过期失效；已支付订单不可取消、重复支付幂等
- 周期：跳 9 周后 week_index 封顶 4 且任务仍可完成；周计划动态适配真实完成进度（完成入门A/进阶A 后推进到入门B 变体，重测保留不重复出现）；结业 task_count 与任务记录一致

## 三、AI 评价质量样本集结果与限制

- 工具：`cd backend && uv run python -m evaluation.run_eval`；样本集 8 类（正常/优秀/敷衍/离题/复制题干/超长 9000 字/重复/注入）
- Mock 结果：6/8 全项通过。结构完整 8/8、证据引用可溯源 8/8、抗注入膨胀 8/8、重复一致 ✓
- 未通过 2 项：离题/复制题干"均分≤2"严格口径（Mock 评分下限为 3，数学上不可达）——已用 xfail(strict) 固定，Mock 修复后会以 XPASS 报警
- 限制声明：**Mock 结果只证明流程与口径正确，不代表真实大模型效果；GLM 真实评估未验证**（GLM_API_KEY 未配置时运行器自动跳过）。已发现并记录：Mock 无语义判别、证据摘取策略对长句注入有理论风险——均为真实模型接入时的重点测试项
- 可追溯：每次 AI 评估记录 ai_model + prompt_version；重新评估使旧记录 superseded（保留留档、不计入画像与展示）

## 四、数据结构变化与回退方案

新增列（均可空/有默认，SQLite create_all 自动迁移；旧库如需保留数据请手工 ALTER）：
- users: token_invalid_before、auth_method
- evaluations: superseded、ai_model、prompt_version
- orders: scope_id
回退：全部新列为可空/带默认，回退到上一版代码可直接运行（旧数据不受影响）；无破坏性迁移。
