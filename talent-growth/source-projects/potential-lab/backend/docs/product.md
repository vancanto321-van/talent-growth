# 产品定义：天赋实验室

## 一句话

帮用户发现天赋线索、用真实任务验证、并给出可执行培养路径的小程序（后续扩为 App）。

## 核心产品原则

对外话术可以是"天赋发现"，内部实现是**「线索 → 实践验证 → 培养路径」**三段式：

1. **不输出单一天赋分数**。研究依据：单次问卷或 AI 对话无法区分先天潜力、已有经验和自我印象（Macnamara 元分析：刻意练习仅解释绩效方差 4%–26%；自评量表预测效度弱）。
2. **每条结论必附依据**：线索引用访谈原话；评估引用作品原文；证据充分度用硬规则计算（<2 次任务=线索；≥2 次=初步；≥3 次+独立完成≥4 分+读者反馈=较充分）。
3. **只和自己比**：五维画像（当前表现/学习进步/迁移保持/持续意愿/证据充分度），不输出人群百分位。
4. **独立 vs AI 辅助分开统计**：知道提升来自哪里。
5. **保持性检验**：入门/进阶任务评估后自动安排 7 天后的迁移重测（简化 FSRS 思想）——隔几天、换题目还会不会做。
6. **防止过早收窄**：每周计划固定保留一个"新方向体验"任务。

## 用户流程

```
探测访谈(6题) → 候选线索(带依据) → 选3个方向开4周周期
    → 每周计划(主方向任务+新方向体验+周回顾)
    → 今日任务 → 做任务 → 提交 → AI按rubric初评 → 自评 → 真实读者反馈
    → 7天后保持性重测 → 五维画像更新 → 天赋组合建议(方向×方向→能力→职业路径)
```

## 五维画像口径

| 维度 | 计算 | 说明 |
|---|---|---|
| 当前表现 | 最近一次评估均分（1-5 → 0-100 展示） | 参考历史均分 |
| 学习进步 | 进阶/迁移阶段 vs 入门阶段同口径差值 | 只作"值得继续"的证据 |
| 迁移保持 | 重测成绩 / 常规基线 | ≥90% 保持住了 |
| 持续意愿 | 自评"还想练"均分 | 新鲜感过后的意愿 |
| 证据充分度 | 硬规则三档 | 线索/初步/较充分 |

所有计分在 `backend/app/services/scoring.py`，模型不参与计分。

## 内容资产（可持续扩充）

- `content/directions.yaml`：6 个天赋方向（首批全部可在电脑上验证；线下方向后续加入）
- `content/tasks.yaml`：18 个任务模板（每方向 入门→进阶→迁移，含 rubric）
- `content/combinations.yaml`：10 条组合图谱（方向组合→能力→职业路径→起步动作）
- `content/interview.yaml`：6 个访谈问题 + 信号词表
- `content/assessment.yaml`：行业潜力测评题库（12 特质 × 4 题 = 48 题，含 12 道反向计分题）
- `content/industries.yaml`：12 个行业图谱（特质权重 + 四步培训路径 + 三档收入行情 + 3 条线下自查任务）
- `content/child_assessment.yaml`：儿童版题库（家长观察版 3-6 岁 / 儿童自答版 7-12 岁，各 48 题）
- `content/child_types.yaml`：8 个儿童类型，每个含日常表现、培养总则、4 周月度培养计划、避坑提醒、资源建议

### 行业潜力测评体系（对标性格分析网站的"问卷→结果"体验）

用户就像做大五人格测试一样做完 48 题（1-5 认同度，约 5 分钟），立刻得到：

1. **12 项特质分**（0-100）：表达沟通、逻辑分析、审美创造、技术动手、身体素质、精细操作、共情关怀、说服进取、统筹组织、抗压韧性、专注耐心、数字敏感。
2. **12 个行业潜力排行**：销售/商务、竞技跑步、外科医生、教师/培训、软件开发、设计/创意、创业/经营、金融/投资、护理/康复、内容创作、项目管理/运营、法律/合规。潜力分 = Σ(行业特质权重 × 特质分)，程序计算、权重公开可解释。
3. **每个行业点开即得**：该行业看什么（权重条）、**短板训练优先级**、四步培训路径（每步有具体动作和过关标准）、收入行情（入行/成熟/头部——头部即"最好的市场行情"下的赢家水平，附分化与周期风险提示）、3 条 3 天可完成的线下自查任务。
4. **与验证闭环衔接**：一键把"潜力分"转成候选线索，进入 4 周任务验证周期——问卷给你方向，任务给你答案。

定位边界：问卷结果叫"潜力参照"（自答），不叫"天赋判定"；行业列表与题库都是 YAML 资产，扩行业=加一份配置。正式上线前需做小样本信度检验并更新收入数据口径（见 compliance.md）。

### 儿童版（对标国际研究的观察问卷 + 类型化培养方案）

**理论来源（已核实的授权边界）**：八个观察维度参照哈佛大学加德纳教授的多元智能理论（自编中文观察题，官方明确无"加德纳认证测评"，故不宣传为哈佛量表）；毅力与思维模式概念来自宾大 Duckworth、斯坦福 Dweck 的公开研究（原量表版权限非商用，故为自编改写题）。不可复用的知名儿童量表（WISC 智力测验、Project Spectrum、VIA-Youth、CBCL）均未使用。

**流程**：家长观察版（3-6 岁，家长代答）或儿童自答版（7-12 岁）→ 48 题 → 8 个类型（最高维度归属：语言小达人/逻辑小侦探/空间建筑师/音乐小精灵/身体小健将/人际小领袖/内省小思想家/自然观察家）+ 毅力/思维模式两项"学习态度指标"（偏低给专项建议）。

**商业化**（配置在 `config.py`，开发期走模拟支付，正式走微信支付）：
- 完整报告 **¥5/次**：8 维度全分 + 类型深度解读 + 态度建议（免费可见类型预告）
- 月度培养方案 **¥29/月**：全部 8 类型的 4 周计划（每周主题 + 3 个活动 + 家长要点 + 避坑 + 资源），每月更新主题

**定位边界**：类型 = 当下行为倾向，非定性标签；建议 3-6 个月重测观察变化；不替代专业评估。
