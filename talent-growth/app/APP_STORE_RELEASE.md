## App Store 文案草案

**名称**

孩子成长

**副标题**

0–8 岁里程碑与陪伴记录

**关键词**

育儿,成长记录,里程碑,亲子陪伴,宝宝,儿童发展,打卡,早教,安全

**简介**

把 0–8 岁儿童发展里程碑、陪伴建议、安全提醒和成长记录放进一个清晰、温暖的家庭工具里。

孩子成长提供 434 项分龄里程碑，覆盖大运动、精细动作、语言沟通、认知、社会情感、生活自理和创造力七个领域。家长可以按年龄查看观察要点与引导方法，记录文字和照片，完成每日陪伴打卡，并通过趋势统计回顾变化。

主要功能：

- 0–8 岁分龄成长地图与阶段解锁
- 434 项里程碑及详细引导方法
- 陪伴指南、安全提醒和逐年物品建议
- 文字、照片和里程碑关联记录
- 多宝宝独立档案
- 每日打卡、成长经验和趋势统计
- 本地 JSON 数据备份与恢复

家庭档案和照片默认只保存在当前设备。当前版本没有账号、广告、第三方分析或自动云上传。

成长里程碑用于帮助家长持续观察，不是考试，也不替代医疗诊断。如发现明显技能倒退或持续异常，请及时咨询专业医疗人员。

**首版更新说明**

- 上线 0–8 岁成长里程碑、陪伴、安全和物品内容
- 支持多宝宝档案、成长记录、照片与每日打卡
- 支持成长趋势统计和本地备份恢复

**建议分类**

- 主分类：生活
- 次分类：教育

## App 隐私问卷建议

按当前代码与服务状态，开发者不接收任何用户数据，因此 App Store Connect 的“数据收集”应选择“不收集数据”。如果后续接入云同步、推送、崩溃分析、统计或客服 SDK，必须在发布该版本前重新评估并更新隐私清单、应用内说明和商店问卷。

相机与相册只在用户主动添加照片时调用；备份只在用户主动打开系统分享面板时发送到用户选择的目标。

## 审核备注草案

App 无需登录。首次打开后创建一个昵称和生日即可进入全部核心流程。相机和相册权限仅在“记录 → 添加照片”时请求。所有家庭数据默认保存在设备本地；“我的 → 查看隐私与数据说明”可查看完整说明。

## Xcode 安装后的验收顺序

```bash
cd app
npm run ios:prepare
npm run ios:check
npm run ios:build
npm run ios
```

随后在 Xcode 中：

1. 选择 Apple Developer Team，并确认 Bundle ID 唯一可用。
2. 在至少一台当前 iPhone 模拟器和一台较小屏幕模拟器运行核心流程。
3. 真机验证相机、相册、分享、离线启动、杀进程重启和数据持久化。
4. 使用 Release 配置执行 Analyze。
5. Product → Archive，完成 Validate App，再上传 App Store Connect。
