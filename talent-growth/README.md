> 下载本仓库后首次使用，请先看[根目录快速开始](../README.md)：在仓库根目录运行 `npm start`，即可同时启动网页和本机备份服务。以下内容保留产品与早期工程说明。

> 接手开发请先看 [Codex 交接说明](START_HERE_CODEX.md)。2026-10-23 已上线 v2.3：624 个活动、14 个学习领域与能力星球。下文部分数量与原生发布说明保留历史口径，最新状态见 [腾讯云发布记录](docs/腾讯云部署记录-2026-10-23.md)。

全年龄探索网页版以真实小任务帮助自己与孩子发现兴趣线索、练习能力并尝试生活与工作中的应用；同时保留 0–8 岁成长记录小程序。

## 全年龄探索

- 6 个年龄入口：0–2、3–6、7–12、13–17、18–59、60+。
- 9 个探索领域，540 张实践任务卡：6 个年龄阶段的每个领域各有 10 项，每张卡都有时间、材料、步骤、成果、观察线索、反思与迁移方法。
- 基础独立于年龄选择：初次接触、已有基础、真实应用；每张卡提供三种可调整做法。0–2 岁按照护者的玩法熟悉程度组织，不要求孩子达成表现。
- 任务完成方向用五档电量记录，每个方向分别保存，总电量显示平均进度。
- 记录真实尝试、投入感、精力、独立/协助方式和他人反馈，逐步形成探索线索。
- 四周培养内容与 14 天练习计划，将兴趣转化为可重复的能力；18 组能力组合给出可探索的生活和工作应用。
- 自己与家人各自独立的档案、进度和尝试记录；可导出/恢复文本备份。
- 个人起点：按目标、可用时间、参与方式和基础推荐三个项目，展示推荐理由与明确的起步版。
- 探索周报：对照最近七天与前七天的真实记录，分别整理投入感、具体变化和使用反馈，不生成天赋分数。
- 作品与变化：按项目回看多次尝试、作品版本、他人反馈和实际使用；兼容原有记录。
- 可选账号备份：账号登录后手动上传、跨设备恢复，保留最近五个云端版本；恢复前确认，版本或账号冲突时中止。默认仍可本地使用，不自动合并记录，不同步照片文件。

内容详见 [全龄潜能实践内容](docs/talent-content.md)，迁入的源项目位于 `source-projects/potential-lab/`。

## 功能

- **成长卡片探索**：首页按年龄阶段横向浏览；进入阶段后按领域筛选成长项目，项目以可左右滑动的大卡呈现，打开后查看成长简介、引导与可点亮的完成方向。方向完成度以电量条展示，并与观察/达标状态分开保存。

- **闯关式年龄段解锁**：默认解锁 0-1 岁；当前年龄段里程碑达标 ≥ 50% 即自动解锁下一年龄段，弹窗庆祝。
- **等级与经验**：标记达标 +50 经验、已观察 +10、每条成长记录 +5；经验累计升级（萌新爸妈 → … → 传奇爸妈）。
- **领域徽章**：某年龄段某领域里程碑全部达标 → 获得该领域徽章。
- **里程碑体系**：6 个年龄段 × 7 大领域 × 434 项里程碑，每项含八段内容（功能/达成标准/怎么引导/做完整/表现与解读/达标标准/后续方向/活动推荐）。
- **陪伴指南**：每日作息节奏、场景话术表、亲子习惯、家长自我照顾。
- **安全事项**：三大风险、居家/户外/饮食/玩具/社交安全清单、急救、发育警示信号。
- **逐年物品清单**：0-8 岁逐年采购清单含使用年限与磨损/更新速度。
- **随手记录**：文字 + 照片成长时间线，可关联里程碑。
- **每日打卡**：按日期快速勾选当天观察/陪伴的里程碑，记录连续打卡天数。
- **成长统计**：达标进度、领域分布、近 12 周记录趋势可视化。
- **多宝宝档案**：可添加多个孩子，各自独立的档案、进度、记录与打卡，一键切换。
- **本地备份恢复**：可在「我的」页将档案、进度和记录复制为备份文本，也可从剪贴板恢复（支持多宝宝与旧版单宝宝备份）。

## 运行

1. 用微信开发者工具打开本目录（`project.config.json` 已配置正式 AppID，可直接预览）。
2. 「我的」页添加宝宝 → 填写宝贝昵称与生日 → 保存；系统会按生日开放对应年龄段内容。
3. 进入当前关卡，点里程碑标记「观察/达标」，达标后会涨经验、可能解锁下一关。
4. 「记录」页可随手记成长、打卡；「我的」页看等级/徽章/闯关进度/成长统计。

## iOS / Android App

项目已增加 `app/` 跨平台 App 工程；iOS 原生工程已经生成，使用 Swift Package Manager 管理依赖，不需要 CocoaPods。首次使用先安装依赖：

```bash
cd app
npm install
npm run ios:prepare   # 同步内容、运行测试并更新 iOS 工程
npm run ios:check     # 检查权限、图标、配置与原生资源
npm run ios:build     # 完整 Xcode 已安装时构建模拟器 App
npm run ios           # 用 Xcode 打开 iOS 工程
```

iOS 工程位于 `app/ios/App/App.xcodeproj`，最低支持 iOS 14。正式安装到 iPhone 或上架前，需要安装完整 Xcode，并在 Xcode 中选择 Apple Developer Team 完成签名。当前 App 使用本地存储，云同步、推送和商店发布配置仍需接入实际账号与服务。

iOS 版已包含应用内隐私说明、Apple 隐私清单、输入与备份安全校验、iOS 14 兼容检查和 5 项自动化回归测试。商店文案、隐私问卷建议及签名验收清单见 `app/APP_STORE_RELEASE.md`。

## 说明

- 数据存于小程序本地缓存（`wx.setStorageSync`），换设备不会自动同步；可在「我的」页导出/恢复文本备份。照片保存在当前设备本地，备份文本不会携带照片文件；如需多端同步可接入微信云开发。
- 里程碑是参考区间，非 KPI；发现明显偏离请以医生评估为准。
- 解锁阈值、经验值在 `utils/gamify.js` 顶部常量可调。
