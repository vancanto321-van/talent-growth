# 天赋生长

> **每个人都是自己天赋的园丁。**
>
> 我们不急着给一朵花命名，也不替它决定应该长成什么样；我们一起照料自己的花园，看它在一次次真实尝试里长出怎样的五彩缤纷。

## 为什么：我们需要一条不被统一模具定义的人生路径

我们从相似的教育模具中长大：相似的课程、相似的评价、相似的“正确答案”。它让很多人学会了适应标准，却没有足够的时间和土壤去辨认自己真正感兴趣的事、擅长的方式，以及愿意长期投入的方向。

于是，有些能力从未被看见，有些兴趣还没发芽就被放下，有些人并不是不努力，而是一直在不适合自己的土壤里用力。无法获得合适的教育，是许多人的无奈；找不到自己的方向，则可能变成个人发展的困局。今天反复的内卷和疲惫，很多时候也来自兴趣、能力与现实机会之间迟迟没有找到合适的连接。

**天赋如果没有合适的教育，仍然只是一颗种子；没有适合自己的土壤，再多浇水也很难长成参天大树。** 天赋生长因此而来：为每个人提供一条可以从今天开始的自我培养路径，帮助那些尚未发芽的种子，获得一次被看见、被尝试、被持续照料的机会。

## 是什么：一个让每个人培育自己花园的全年龄培养系统

天赋生长是一个由个人借助 AI 构建的全年龄培养系统，面向幼儿、儿童、青少年、成人和晚年，也支持照护者为孩子记录。它不替你宣布“你是什么样的人”，而是把成长拆成可以亲自参与的过程：从一件小事开始，留下作品和反馈，回看变化，再决定下一步。

它包含 6 个年龄入口、624 个活动、14 个学习领域、14 天培养计划、探索周报、作品与变化、多成员档案、本地备份恢复和 PWA 离线访问。能力星球展示花园里已经发生的探索，不用于天赋测量、能力排名或职业预测。

## 怎么办：从一颗种子开始，照料一次真实尝试

1. **找到自己的起点**：按年龄、处境、目标、可用时间和基础，选择一件今天能够开始的小事。
2. **完成一次小实验**：按照材料、步骤和提示行动；可以独立完成，也可以邀请家人或伙伴参与。
3. **记录真实变化**：留下作品、投入感、精力、反馈和停止信号；不参与也可以被记录，不需要把自己变成分数。
4. **回看自己的花园**：从多次尝试中看见什么条件让自己更愿意继续，哪些地方需要换土、调整节奏或暂时休息。
5. **决定下一步**：继续、缩小、换材料、换表达方式，或暂停一段时间——让培养服务于人，而不是让人服从系统。

AI 在这里不是裁判，也不是替你规划人生的权威。它辅助内容组织、年龄适配、反馈整理和下一步探索；产品坚持不做医学诊断、不做天赋测评、不做人与人排名。我们希望帮助每个人从“我到底有没有天赋”的焦虑，走向“我今天可以照料哪一颗种子”的行动。

## 下载后开始使用

适用于 Windows、macOS、Linux。电脑需要先安装 **Node.js 22 或更高版本**（包含 npm）。无需 Python、微信开发者工具、Xcode、数据库或第三方 API 密钥，也无需运行 `npm install`。

1. 在 GitHub 点击 **Code → Download ZIP**，下载后完整解压；也可以使用 GitHub Desktop 克隆仓库。
2. 在解压后的仓库根目录（包含本 README 和 `package.json`）打开终端，运行：

   ```sh
   npm start
   ```

3. 等终端显示启动成功，在浏览器打开 **<http://127.0.0.1:4184/growth/>**。
4. 从「发现」选择一件小事开始；在「家人」添加自己或家人的独立档案。

展示版与参赛准备：见 [`talent-growth/docs/Web展示版说明.md`](talent-growth/docs/Web展示版说明.md) 和 [`talent-growth/docs/参赛演示流程.md`](talent-growth/docs/参赛演示流程.md)。网页支持安装为 PWA；首次在线打开并缓存后，基础页面可离线使用。当前阶段 macOS 只提供未签名预览 DMG，Windows 安装包尚未构建。

桌面版已开始准备，采用 Tauri 2 复用 Web 前端；构建配置和平台发布前检查见 [`desktop/README.md`](desktop/README.md)。当前提供未签名、未公证的 Apple Silicon DMG 预览包，见 [最新桌面版](https://github.com/vancanto321-van/talent-growth/releases/tag/v0.7.7)。

也可以双击根目录的 `start.bat`（Windows）或 `start.command`（macOS）。macOS 若不允许双击脚本，直接使用上面的终端命令。Linux 使用 `npm start`。程序会同时启动网页与本机账号备份服务。

使用时保留终端窗口；按 **Ctrl+C** 停止两个服务。下次运行相同命令即可继续使用。基础活动和记录功能不依赖互联网；外部资料和作品链接需要联网。

## 记录保存在哪里

| 内容 | 保存位置 | 注意事项 |
| --- | --- | --- |
| 探索档案、尝试、电量、周报数据 | 当前浏览器的本地存储 | 使用同一浏览器、同一地址；无痕模式或清理站点数据可能丢失记录 |
| 手动上传的账号备份 | 本仓库根目录 `.local-data/growth-sync/` | 账号属于这台电脑上的服务，保留最近五版；没有自动上传或密码找回 |
| 孩子成长档案的照片 | 当前浏览器的本地数据库 | 方向备份不包含照片文件，重要照片应另行保存 |

**下载本项目不会获得原作者或其他使用者的记录。** 本机账号与正式网站的账号各自独立，备份请求只发往本机。此启动方式仅限当前电脑访问，不提供跨设备同步。

换电脑时，在「家人 → 本地备份与恢复 → 导出方向备份」导出 JSON 文件，在新电脑启动项目后恢复。孩子成长档案使用其自身的备份入口；照片文件需另行保留。升级项目文件前也建议导出备份，并保留 `.local-data/`。不要把个人备份文件或 `.local-data/` 上传到 GitHub。

## 常见问题

- **提示找不到 node/npm**：安装 Node.js 22 或更高版本，然后重新打开终端。可用 `node --version` 查看版本。
- **端口被占用**：先停止另一份本项目服务，再重试。也可换端口，例如 `node scripts/start.mjs --port 4185 --api-port 18140`。更换网页端口会使用独立的浏览器存储，需要先导出再恢复记录。
- **提示备份目录正在使用**：同一目录只允许启动一份服务，避免两个进程同时写入备份。先在原终端按 Ctrl+C；若曾断电或强制结束进程，确认原服务已停止后，才可删除根目录 `.local-data/growth-sync.lock` 再启动，不要删除 `growth-sync/` 数据目录。
- **直接双击 HTML 页面打不开**：使用启动命令，通过上面的 HTTP 地址访问；项目使用 JavaScript 模块。
- **账号与正式网站不通用**：本机账号备份独立运行，不连接原作者服务器。跨电脑可使用导出/恢复。
- **页面没更新**：刷新页面，并确认启动的是当前解压目录；不要同时启动旧版 macOS `local-preview.sh` 服务。

## 开发与部署

当前网页版源码位于 [`talent-growth/app/www/`](talent-growth/app/www/)，源内容位于 [`talent-growth/data/`](talent-growth/data/)，账号备份服务位于 [`talent-growth/server/`](talent-growth/server/)。

更新源内容后，在仓库根目录执行：

```sh
npm run sync:data
npm run build:web
```

静态包输出到 `talent-growth/outputs/tencent-cloud/`，构建不会自动部署。普通本机使用无需执行这些命令；已生成的页面和内容随源码一起提供。iOS、Android 与微信工程保留供单独开发，不在本机启动命令的构建范围内。

若要让其他设备访问同一套账号与备份，需要另行部署静态网站和账号服务，配置自己的域名、HTTPS 与持久化数据目录，参考 [服务说明](talent-growth/server/README.md)。本机启动使用的 HTTP 开发配置不能直接用作公网服务。历史腾讯云脚本包含原作者的站点配置，部署自己的站点前需先调整。
